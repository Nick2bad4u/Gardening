# Original nursery labels

This folder preserves the supplier labels that came with the starter cactus
group. `nursery-labels` is more accurate than the original `Nursery-Cards`
name: some evidence is a printed sleeve, a sticker, or only one side of a
label. The photos were captured on 2026-07-23 and renamed by the plant name and
visible label face.

A nursery label is useful provenance, but it is not automatically a correct
botanical identification. The original “Opuntia Cylindrica Cristata” sleeve is
retained under a filename that records the likely Ming Thing mislabel.
