# Plant anatomy illustrations

These illustrations accompany the collection's plant profiles. Each image uses
four numbered features; the corresponding labels and explanations remain
selectable, accessible text on the page.

The images were created with OpenAI's built-in image-generation tool for this
collection. They are educational schematics, not photographs, measurements, or
evidence of an individual plant's identification. Hidden roots and other
illustrated structures are general representations; they do not establish the
root connections of plants in shared containers. Botanical uncertainty is
described in the accompanying profile.

The full generation prompt, review status, botanical sources, and image path
are maintained in each matching JSON record under
[`docs/plants/discovery`](../../docs/plants/discovery/). The final WebP images
are retained here so the website does not depend on a private generation cache.
Original tool outputs are not part of the published site.

This artwork is separate from the licensed reference photographs in
[`assets/plants`](../plants/) and the collection's original photographic
evidence. Their existing attribution and rights remain unchanged.
