Manual sensor plan

Put it at canopy height in shade, between the tables if possible. Keep it outside the direct fan jet and off glass, Mylar, and wet trays.

Aug 3–16 7:30 p.m. daily: current T/RH + both 24-hour ranges.
Aug 17 onward Sunday 7:30 p.m.: current, 24-hour, and all-time extremes.
Comfort

About 65–85°F and 30–55% RH is a useful broad observation band.

Check

Investigate a 24-hour low below 55°F or high above 95°F.

Humidity

If the 24-hour RH minimum is above 60%, improve spacing/airflow and be cautious with cool, slow-drying pots. A brief maximum above 60% is fine; use the sensor-driven dehumidifier rule rather than running it every day.
