# Plant profiles

Last updated: 2026-08-01

These pages combine botanical background with practical notes for current and
historical collection records. They are reference guides, not fixed watering
schedules. Light and water advice assumes the current small pots, fast-draining
mix, moving plants out of prolonged rain, and the AW200SE indoor setup.

The [AW200SE/E25 guide](../equipment/vivosun-aw200se.md) explains the PPFD,
DLI, lux, distance, and placement ranges used in the profiles.

The same research is published as
[**The Fenton Collection browser field guide**](../plant-booklet/), with a
cover, searchable contents, one magazine-style reading page per record,
licensed reference photography, keyboard navigation, dark mode, and print
styling.

An identification marked **probable** is still a working hypothesis. Its page
describes the best current match and calls out evidence that could confirm or
change it.

The [pot-label reference](./labels.md) collects SUPVAN E11 print layouts, short
permanent label IDs, native origins, first-description years, warnings, and the
three special orientation labels for all living plants.
