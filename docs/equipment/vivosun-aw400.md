## What the Upgrade Changes

- **Tunable spectrum and UVA:** the AW400 manual documents both, including
  UVA in its Flower-mode description. The manual does not establish an
  independently scheduled UVA channel, so no separate UVA timer is assumed.
- **Far-red is shared:** the [AW400SE manual][se-manual] also lists 730 nm
  far-red. Far-red alone is not a feature gained by this switch.
- **Samsung 301H EVO:** the selected seller listing explicitly names these
  diodes. This identifies the advertised configuration; no whole-fixture efficacy
  advantage or electricity saving has been calculated from the diode name.
- **Same planned footprint, heavier fixture:** the AW400 manual lists 16.82 lb,
  compared with 12.5 lb for the canceled SE model. The mount note uses the AW400
  figure; verify the supplied fixture label before installation.

For this collection, the extra cost buys spectrum choices while keeping the
intended wider display. It does not establish that these cacti and succulents
need UVA or will grow better because it is present. Keep the species' light
needs and actual exposure as the basis for placement. The roughly $70 premium
is owner-reported, not a current retail-price comparison.
