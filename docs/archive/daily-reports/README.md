# Retired Daily Report Archive

The daily weighing and watering report was retired on **November 9, 2026**.
The owner no longer uses these reports and now waters differently. The previous
report policy is historical advice, not the current care plan. No replacement
watering policy is established by this retirement.

The existing **Garden — Watering & Weighing** automation was verified **paused**
on November 9, 2026. It remains paused; this archive does not authorize resuming
it or publishing new reports.

## Preserved Records

This directory preserves all **31 dated JSON inputs**, from **September 14 through
October 14, 2026**, byte for byte. Their dates, source timestamps, observations,
recommendations, and schema versions are unchanged. They describe the evidence
and advice recorded then, not fresh workbook reads or proof that care occurred.

The former operating documents are retained separately:

- [Historical runbook](./historical-runbook.md)
- [Historical task prompt](./historical-task-prompt.md)
- [Historical agent instructions](./historical-instructions.md), renamed so they
  are no longer an operative `AGENTS.md`

Old report URLs show a retirement notice rather than a latest-care plan. The
[plant tracker](https://nick2bad4u.github.io/Gardening/tracker/),
[pot histories](https://nick2bad4u.github.io/Gardening/pots/), and
[watering map](https://nick2bad4u.github.io/Gardening/watering/) remain separate
observation tools. Retiring reports does not change recorded History or the
logger's measurement calculations.
