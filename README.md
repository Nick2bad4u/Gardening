# Gardening

This is my low-pressure garden notebook. The current focus is my cactus and
succulent collection, especially learning how to use the VIVOSUN AW200SE grow
light without turning the hobby into a science project.

## Current notes

- [Plant collection](docs/collection.md) — working IDs, confidence, and plant
  status
- [Setup and equipment](docs/setup.md) — light, controller, pots, soil, and
  current arrangement
- [Care notes](docs/care-notes.md) — the practical light, water, airflow, and
  recovery plan

Plant names based only on photos are treated as working IDs and can be updated
when a flower, label, or better close-up gives stronger evidence.

The repository will stay intentionally lightweight. Logs, photos, and templates
can be added when they become useful.
